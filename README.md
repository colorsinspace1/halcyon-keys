# Halcyon Keys

Halcyon's soft ambient tones for the Teenage Engineering OP–XY, played in a scale,
built with the unofficial [Open-XY SDK](https://github.com/etcetc000/open-xy). By
Colors In Space.

The white keys are the scale: from middle C, each white key plays the next note of
the chosen Scale from the chosen Root. The ten black keys of each two octaves are ten
songs: hold one and it plays its own slow chord progression, four to eight
chords long. The songs are made by rules from the scale's own notes, different
for every Root and Scale (960 in all), so each scale has its own character:
dorian leans on its bright IV, lydian floats on its II, phrygian on the dark II
a half step up. Each song has its own voicing (open, close, wide,
sus2, add 11, add 9, third on top, low and dark, fifths, high shimmer), and some
open away from home. Every song sits in the same register, whichever black key
plays it, and the same Root, Scale and key always give the same song. A song plays like hands on keys: each chord is
held for three quarters of its time, then let go to ring out, and the next one
swells in (with Swell) as it fades. A chord is four Halcyon voices, with at most two more
ringing out (lighter, without Air, Hiss, Ensemble or Age as they fade), so a held
black key costs about five notes' worth of processing. Set it to the key of your
sequence and play over it. Pentatonic scales have five notes an octave, so they
climb a little faster than the keyboard. Each key is its own note, so the OP-XY's
envelopes, filter and LFO shape every note as usual.

| --- | --- |
| **Drift** | wandering tape speed and a breathing filter |
| **Air** | late copies an octave up, then down |
| **Progress** | how long each chord of a black key's song lasts, from 30 s down to 4 s (off: the first chord only) |
| **Age** | tape saturation, a rounded top and a little wobble; turned up, more tape hiss that breaks up into particles |

The screen is Halcyon's fog lake: each note drops a ripple on the water.
